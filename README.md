### 线路延迟，不用点进去看
1.每张卡片可自定义线路：电信 / 联通 / 移动，最多能配 8 条线路

2.延迟越高颜色越红；整轮超时直接画红格，丢包率单独一条
3.鼠标悬停看每一格的时间段和延迟，手机上点一下柱子也行
4.想展示别的线路？点线路名直接换
